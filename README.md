# 출장비 정리기

## 쓰기 전에

1. 넣은 파일은 브라우저를 떠나지 않는다(F12 --> Network 로 확인).
2. 처방은 rules/ 의 파일을 고친다.

## 쓰는 법

1. 사이트를 열고 엑셀 파일(.xlsx · .xls · .csv)을 끌어다 놓는다.
2. 파일 이름에 맞는 처방이 `rules/`에 있으면 처방과 이유가 표로 나온다. 없으면 «이 파일에 맞는 처방이 없습니다.»가 뜨고, 처방 파일(.json)을 직접 골라 올릴 수 있다.
3. «규칙대로 정리»를 누르면 정리 전후 행 수, 지운 행, 고친 값, 표시한 행, «두 번 돌려도 같은 결과»가 나온다.
4. 정리본과 바꾼 기록을 내려받는다(.xlsx라 엑셀에서 한글이 깨지지 않는다).
5. 정답 파일이 있으면 «정답과 대조»에서 골라 비교할 수 있다. 정답 파일도 브라우저 안에서만 연다.

## 처방 고치기

- 처방 파일은 `rules/<파일 이름>.json`이다. 예: `출장비정산.xlsx` → `rules/출장비정산.json`.
- 새 처방 파일을 만들면 `rules/목록.json`의 `files`에도 이름을 더한다. 목록에 있는 이름만 사이트에 요청하므로, 목록에 없는 파일 이름은 사이트로 가지 않는다.
- 처방마다 `why`(이유)와 `owner`(정한 사람)를 적는다.
- 처방은 위에서 아래 순서로 적용된다. 모양 맞추기 → 표시 → 같은 줄 지우기 순서로 둔다.

| type | 하는 일 |
|---|---|
| `replace` | `map`에 적힌 값을 바꾼다 (`trim`이면 앞뒤 공백도 지움) |
| `number` | `remove`에 적힌 글자를 떼고 숫자로 바꾼다. 못 바꾸면 표시 |
| `date` | `read_formats`의 날짜를 `target` 모양으로 바꾼다. 못 읽으면 표시 |
| `keep` | 고치지 않는다 (해당 줄 수만 센다) |
| `flag` | 조건에 맞으면 `_표시` 칸에 이유를 적는다 |
| `consistent` | `group_by`가 같은 줄끼리 `column` 값이 둘 이상이면 표시 |
| `dedupe` | 모든 칸이 같은 줄은 처음 것 하나만 남긴다 |

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면 |
| `clean.js` | 처방 파일을 읽어 실행하는 정리 엔진 |
| `lib/` | SheetJS(엑셀 읽기·쓰기)와 라이선스 |
| `rules/` | 처방 파일 |
| `data/출장비정산.xlsx` | 시험용으로 지어낸 엑셀 (실제 개인정보 없음) |

## 내 컴퓨터에서 열기

`index.html`을 더블클릭하면 처방을 자동으로 찾지 못한다(브라우저 보안 규칙). 폴더에서 아래를 실행하고 http://127.0.0.1:8000/ 을 연다.

```
python -m http.server 8000 --bind 127.0.0.1
```
